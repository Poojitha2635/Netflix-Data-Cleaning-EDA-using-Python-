#  Netflix Data Cleaning & Exploratory Data Analysis using Python

##  Project Overview
This project demonstrates the complete data cleaning and exploratory data analysis (EDA) process using the Netflix Movies and TV Shows dataset. The dataset was cleaned using Python and Pandas in Google Colab, followed by visualizations to understand content trends and patterns.

---

## Objectives
- Clean raw Netflix data.
- Handle missing values.
- Remove duplicate records.
- Convert data types.
- Perform exploratory data analysis (EDA).
- Generate business insights using visualizations.

---

## Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Microsoft Excel

---

#Dataset
Netflix Movies and TV Shows Dataset (.xlsx)

# Project Workflow

### Step 1: Import Libraries
- Import Pandas, NumPy, and Matplotlib.

### Step 2: Load Dataset
- Upload the Netflix dataset into Google Colab

### Step 3: Data Inspection
- Check dataset shape.
- View column names.
- Display first and last records
- Check missing values.
- Check duplicate records
- Review data types.

### Step 4: Data Cleaning
- Remove duplicate rows.
- Handle missing values
- Standardize text values.
- Convert date columns
- Remove unnecessary columns.
- Rename columns if required.

### Step 5: Exploratory Data Analysis (EDA)
- Movies vs TV Shows
- Content by Country
- Content Rating Distribution
- Release Year Analysis
- Top Directors
- Top Genres
- Duration Analysis
- Year-wise Content Added

### Step 6: Data Visualization
- Bar Charts
- Pie Charts
- Histograms
- Line Charts

### Step 7: Save Clean Dataset
- Export the cleaned dataset to Excel.



## Key Insights
- Distribution of Movies and TV Shows.
- Most common content ratings.
- Top countries producing Netflix content.
- Content growth over the years.
- Most popular genres.
